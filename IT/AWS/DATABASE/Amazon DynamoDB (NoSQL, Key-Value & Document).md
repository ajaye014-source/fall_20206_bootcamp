
### **2. Amazon DynamoDB (NoSQL, Key-Value & Document)**

#### **The Core Problem It Solves**

- **The "Relational Scalability Wall":** Traditional relational databases struggle to scale horizontally when dealing with millions of concurrent read/write requests, leading to slow queries or server crashes during traffic spikes.
    
- **Unpredictable Latency & Schema Rigidity:** Solves the need for flexible, schema-less document storage while guaranteeing **single-digit millisecond latency** at _any_ scale.
    

#### **Key Strengths & Ideal Use Cases**

- **Serverless & Fully Managed:** Automatically scales throughput up or down to zero without servers to manage or partition setups to configure manually.
    
- **Best For:** Mobile/web backends, user profiles, session states, shopping carts, gaming leaderboards, and high-throughput ad-tech event streams.
